# Мини-облако

Требования общие:
1) Загрузка файлов на облакр через веб-фронтенд
2) Выгрузка файлов на машину клиента
3) Просмотр загруженных файлов на фронтенде (поплуярные текстовые форматы, видно, изображения)
4) Механизм "поделится" 
5) Лимиты на пространство
6) админский дэшборд (оставшееся место на файловом хранилище, возможно что-то ещё)

используемые инструменты:
база данных: sqlite
java multithreading
java springboot
фронтенд: nextjs
по возможности: использовать уже готовые библиотеки, переиспользование кода, готовых компонентов

использовать докер
